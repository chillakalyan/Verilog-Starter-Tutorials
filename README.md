# Verilog Starter Tutorials

A beginner-friendly collection of TL-Verilog digital design examples using Makerchip.

This repository focuses on learning:
- Digital Logic Design
- RTL Design
- Combinational Circuits
- Sequential Circuits
- FPGA Fundamentals
- Hardware Design Concepts using TL-Verilog

---

# Repository Structure

## 01_Logic_Gates
Basic logic gate implementations in TL-Verilog.

### Included
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- XNOR Gate

---

## 02_Combinational_Circuits
Fundamental combinational circuit implementations.

### Included
- Half Adder
- Full Adder
- Multiplexer
- Demultiplexer
- Encoder
- Decoder
- Comparator

---

## 03_Sequential_Circuits
Sequential circuit implementations using TL-Verilog.

### Included
- Flip-Flops
- Registers
- Counters
- Shift Registers
- Finite State Machines (FSMs)
